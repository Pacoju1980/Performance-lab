PERFORMANCE LAB 1.1.0 — AUDITORÍA INTEGRAL

Objetivo
-------
Eliminar las regresiones repetitivas de importación, fecha, caché y sueño, y dejar una base única e integrada.

CAUSAS RAÍZ IDENTIFICADAS
-------------------------
1. Versiones construidas como parches sucesivos.
   Un cambio podía partir de una copia anterior y sobrescribir una corrección ya hecha.
   Solución: 1.1.0 es un paquete completo; no depende de archivos-parche externos.

2. El mismo mensaje mezclaba dos fallos distintos:
   - iOS/Safari no permite leer el portapapeles.
   - el texto no es JSON válido.
   Solución: ahora se distinguen. Si iOS bloquea la lectura automática, la app abre una caja de pegado manual sin perder los datos.

3. El Atajo y la app no tenían un contrato estable de datos.
   El Atajo entrega campos como PasosFechad, SpO2Fechad, sourse y listas separadas por salto de línea.
   Solución: el importador reconoce explícitamente esas variantes y NO separa fechas por comas.

4. Fechas en UTC frente a fecha local.
   Solución: toda la fecha diaria usa año/mes/día locales; no se usa toISOString() para decidir “hoy”.

5. Caché/service worker podía servir una versión anterior.
   Solución: el service worker queda neutro y se eliminan cachés Performance Lab durante la estabilización.

6. Sueño se calculaba parcialmente.
   Solución: se reconocen Ligero, Profundo, REM, Durmiendo, Vigilia y En cama; se fusionan intervalos para evitar dobles conteos y se guardan las fases para el hipnograma.

7. El contador de sincronización incluía métricas que Apple Salud no entrega actualmente.
   Solución: cobertura automática = 5 métricas disponibles por el puente actual: sueño, FC en reposo, SpO2, pasos y respiración.

8. No existía una prueba de regresión antes de entregar cada build.
   Solución: se ejecutó una prueba con un payload representativo del formato real del Atajo.

RESULTADOS DE AUDITORÍA
-----------------------
- app.js: sintaxis JavaScript válida con node --check.
- index.html: referencias consistentes con v1.1.0.
- manifest.webmanifest: JSON válido y todos los iconos existen.
- iconos: dimensiones verificadas 180x180, 192x192 y 512x512.
- styles.css: balance de bloques verificado.
- sw.js: sin escritura de caché.
- paquete: un solo app.js; no hay duplicados ambiguos.
- 35 comprobaciones estructurales: 35/35 PASS.

PRUEBA DE REGRESIÓN DEL IMPORTADOR
----------------------------------
Se usó un payload representativo del formato real ya observado:
- sourse
- PasosFechad
- SpO2Fechad
- fechas es-MX con coma y a.m./p.m.
- sueño por intervalos y fases

Resultado:
- cobertura: 5/5
- sueño de prueba: 4 h 16 min
- tiempo en cama de prueba: 4 h 22 min
- pasos: suma diaria correcta
- SpO2: mediana diaria correcta
- respiración: mediana diaria correcta
- fases: persistidas para el hipnograma

CAMBIO CLAVE DE ROBUSTEZ
------------------------
La importación es transaccional: si un paquete no puede interpretarse, el estado anterior se restaura. Un error de importación ya no debe dejar datos parcialmente modificados.

IMPORTANTE PARA DESPLIEGUE
--------------------------
Usar este paquete COMPLETO como una sola versión. No combinar app.js, index.html o styles.css de builds anteriores.
